# مصدر النص القرآني

يعتمد المشروع نصاً عثمانياً من **مشروع تنزيل (Tanzil Project)**.

## جلب النسخة الأصلية

من جذر المشروع شغّل:

```bash
python scripts/fetch_tanzil.py
```

سينزّل البرنامج ملف النص الأصلي وملف بيانات السور من خوادم Tanzil الرسمية، ثم يتحقق من وجود 114 سورة و6236 آية ومن تسلسل أرقام الآيات، قبل حفظ الملفين محلياً.

الملفات الناتجة:
- `tanzil-uthmani.txt`: النص القرآني الأصلي مع ترقيم السور والآيات.
- `quran-data.xml`: أسماء السور وعدد آيات كل سورة.

لا يُعدّل البرنامج النص القرآني ولا يعيد كتابته أو تطبيعه. عند العرض على الصورة تُستخدم معالجة تشكيل بصري فقط لعرض العربية بصورة صحيحة.
