# آيات من القرآن

مشروع لإنتاج مقاطع قصيرة (YouTube Shorts) لآيات القرآن الكريم، بتلاوة مرخّصة للاستخدام، وخلفيات مرخّصة، مع عرض نص الآية واسم السورة ورقم الآية.

## الإعداد المعتمد
- قناة YouTube المستهدفة: `@obaidahshteiwi`
- المعدل المستهدف: فيديو واحد يومياً
- المدة: 30–60 ثانية
- الأبعاد: 1080×1920 (9:16)
- الصوت: تلاوة لقارئ حقيقي، بعد التحقق من إذن إعادة الاستخدام
- الخلفية: مشهد طبيعي مرخّص؛ ويوفر المولّد خلفية مرسومة بسيطة عند عدم تحديد فيديو خلفية
- التكلفة المستهدفة: صفر دولار باستخدام الأدوات المجانية ضمن حدودها

## ما تم بناؤه
- `src/render_short.py`: مولّد محلي يركّب نص الآية ومرجعها مع ملف التلاوة.
- `requirements.txt`: مكتبات Python المطلوبة.
- `config.example.json`: إعدادات نموذجية للمقاس والخط والوسائط.
- `data/used_verses.json`: سجل لمنع تكرار السورة والآية.
- `assets/README.md`: تعليمات إضافة الخطوط والوسائط المرخّصة.

## التشغيل المحلي
1. ثبّت Python 3.10 أو أحدث وFFmpeg (بما فيه ffprobe).
2. ثبّت المكتبات:
   `pip install -r requirements.txt`
3. انسخ `config.example.json` إلى `config.json`.
4. أضف خطاً عربياً مرخّصاً إلى `assets/fonts/`، ثم حدّث `font_path` في `config.json`.
5. أضف ملف تلاوة مرخّصاً مدته بين 30 و60 ثانية، ثم مرّر مساره إلى الأمر.
6. شغّل المولّد يدوياً من جذر المشروع:

```bash
python src/render_short.py --verse "نص الآية بعد التحقق" --surah "اسم السورة" --ayah 1 --audio "assets/audio/recitation.mp3"
```

يمكن تمرير خلفية فيديو مرخّصة عبر `--background "assets/backgrounds/scene.mp4"`. عند عدم تمريرها، ينشئ البرنامج خلفية طبيعية مرسومة بسيطة. يحفظ الفيديو محلياً في مجلد `output/`.

## ضوابط مهمة
- المولّد لا يتحقق آلياً من صحة الآية؛ يجب مراجعة النص والتشكيل واسم السورة ورقم الآية من مصحف موثوق قبل التشغيل.
- لا تستخدم أي تلاوة أو خط أو مشهد قبل التأكد من ترخيصه وشروط استخدامه على YouTube.
- لا تضع كلمات مرور أو مفاتيح API أو ملفات OAuth في المستودع.
- لا ينفّذ البرنامج رفعاً أو نشراً أو جدولة، ولا يتصل بواجهة YouTube.
- لا توجد GitHub Actions أو عمليات نشر تلقائي مفعّلة حالياً.
- لا يوجد نشر تجريبي.
