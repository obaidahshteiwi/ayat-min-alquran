# آيات من القرآن

مشروع لإنتاج مقاطع قصيرة (YouTube Shorts) لآيات القرآن الكريم، مع نص قرآني من مصدر موثوق، وتلاوة مرخّصة، وخلفية طبيعية، وعرض اسم السورة ورقم الآيات.

## الإعداد المعتمد
- قناة YouTube المستهدفة: `@obaidahshteiwi`
- المعدل المستهدف: فيديو واحد يومياً
- المدة: 30–60 ثانية
- الأبعاد: 1080×1920 (9:16)
- النص القرآني: Tanzil Uthmani، مع حفظ النص كما ورد دون تغيير
- التلاوة والخلفية المبدئيتان: ملفان من Wikimedia Commons برخصة CC0، مع إعادة فحص بيانات الترخيص وبصمة الملف عند التنزيل
- التكلفة المستهدفة: صفر دولار باستخدام الأدوات المجانية ضمن حدودها

## ما تم بناؤه
- `src/render_short.py`: مولّد فيديو محلي يدعم آية واحدة أو نطاق آيات متتالياً.
- `src/quran_source.py`: قراءة النص الأصلي والتحقق من بيانات السور وأرقام الآيات.
- `src/media_rights.py`: رفض ملفات الصوت أو الخلفية الخارجية ما لم يوجد سجل حقوق صالح.
- `scripts/fetch_tanzil.py`: تنزيل نص Tanzil والتحقق من بنيته.
- `scripts/validate_quran.py`: فحص ملفات النص المحلية.
- `scripts/setup_assets.py`: تنزيل خط Amiri ورخصته إلى الجهاز المحلي.
- `scripts/fetch_starter_media.py`: تنزيل تلاوة سورة الفيل وخلفية نهر بعد التحقق من CC0 وSHA-1 من Wikimedia Commons.
- `tests/`: اختبارات آلية للتحقق من النص والنطاقات وبيانات حقوق الوسائط.

## التشغيل المحلي
1. ثبّت Python 3.10 أو أحدث وFFmpeg (بما فيه ffprobe).
2. ثبّت المكتبات:
   `pip install -r requirements.txt`
3. نزّل نص Tanzil وبيانات السور:
   `python scripts/fetch_tanzil.py`
4. افحص النص:
   `python scripts/validate_quran.py`
5. نزّل ملفات الصوت والخلفية:
   `python scripts/fetch_starter_media.py`
6. ثبّت خط Amiri ورخصته:
   `python scripts/setup_assets.py`
7. انسخ `config.example.json` إلى `config.json`.

لإنشاء فيديو محلي لسورة الفيل (الآيات 1–5):

```bash
python src/render_short.py --verse-range 105:1-5
```

يستخدم البرنامج التلاوة والخلفية وملفات الحقوق المحددة في `config.json`. يحفظ الفيديو محلياً في `output/s105-a001-005.mp4`.

عند استخدام تسجيل أو خلفية أخرى، يجب وجود ملف حقوق محلي صالح. لا يستطيع البرنامج إثبات صحة الإذن القانوني بنفسه، لكنه يرفض الوسائط التي لا تتضمن سجل حقوق واضحاً.
