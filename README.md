# آيات من القرآن

مشروع لإنتاج مقاطع قصيرة (YouTube Shorts) لآيات القرآن الكريم، بتلاوة مرخّصة للاستخدام، وخلفيات طبيعية متحركة، مع عرض نص الآية واسم السورة ورقم الآية.

## الإعداد المعتمد
- قناة YouTube: `@obaidahshteiwi`
- فيديو واحد يومياً (مستهدف)
- مدة المقطع: 30–60 ثانية
- الأبعاد: 9:16
- التلاوة: تسجيل قارئ حقيقي مع التحقق من ترخيص إعادة الاستخدام
- الخلفية: مشاهد طبيعية مرخّصة
- التكلفة المستهدفة: صفر دولار باستخدام الخدمات المجانية ضمن حدودها

## مراحل التنفيذ
1. بناء مولّد فيديو محلي باستخدام Python وFFmpeg.
2. التحقق من النص القرآني وبيانات السورة والآية من مصدر موثوق.
3. إضافة سجل لمنع تكرار الآيات.
4. إعداد GitHub Actions للتشغيل اليدوي فقط في مرحلة التطوير.
5. ربط YouTube Data API بعد موافقة صاحب القناة.
6. تفعيل الجدولة والنشر التلقائي فقط بعد موافقة صريحة.

## ضوابط مهمة
- لا يوجد نشر تجريبي.
- لا توجد جدولة أو عمليات رفع مفعّلة حالياً.
- لا تُستخدم أي تلاوة أو لقطات طبيعة قبل التأكد من ترخيصها.
- يجب مراجعة نص الآية والتشكيل واسم السورة ورقم الآية قبل اعتماد أي فيديو.
