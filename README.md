# آيات من القرآن

مشروع لإنتاج مقاطع قصيرة (YouTube Shorts) لآيات القرآن الكريم، مع نص قرآني من مصدر موثوق، وتلاوة مرخّصة، وخلفيات مرئية، وعرض اسم السورة ورقم الآية.

## الإعداد المعتمد
- قناة YouTube المستهدفة: `@obaidahshteiwi`
- المعدل المستهدف: فيديو واحد يومياً
- المدة: 30–60 ثانية
- الأبعاد: 1080×1920 (9:16)
- النص القرآني: Tanzil Uthmani، مع حفظ النص كما ورد دون تغيير
- الصوت: تلاوة لقارئ حقيقي، بعد الحصول على إذن إعادة الاستخدام من صاحب الحقوق
- الخلفية: مشهد طبيعي مرخّص، أو خلفية مرسومة أصلية يولدها البرنامج
- التكلفة المستهدفة: صفر دولار باستخدام الأدوات المجانية ضمن حدودها

## ما تم بناؤه
- `src/render_short.py`: مولّد فيديو محلي يركّب الآية ومرجعها مع ملف التلاوة.
- `src/quran_source.py`: قراءة النص الأصلي والتحقق من بيانات السور وأرقام الآيات.
- `scripts/fetch_tanzil.py`: تنزيل نص Tanzil وبيانات السور من المصدر الرسمي والتحقق منها قبل حفظها.
- `requirements.txt`: مكتبات Python المطلوبة.
- `config.example.json`: إعدادات الفيديو والخط والوسائط.
- `data/used_verses.json`: سجل لمنع تكرار الآيات.
- `youtube/description_template.txt`: قالب وصف فيديو يتضمن إسناد النص القرآني إلى مصدره.
- `.gitignore`: يمنع إضافة ملفات النصوص القرآنية المحلية وملفات الفيديو والإعدادات الخاصة إلى Git.

## التشغيل المحلي

1. ثبّت Python 3.10 أو أحدث وFFmpeg (بما فيه ffprobe).
2. ثبّت مكتبات Python:
   `pip install -r requirements.txt`
3. نزّل النص والبيانات من Tanzil الرسمي وتحقق منهما:
   `python scripts/fetch_tanzil.py`
4. انسخ `config.example.json` إلى `config.json`.
5. أضف خطاً عربياً مرخّصاً إلى `assets/fonts/`، واضبط `font_path` في `config.json`. خط Amiri متاح برخصة SIL Open Font License؛ راجع موقعه الرسمي.
6. أضف ملف تلاوة لديك إذن واضح بإعادة استخدامها، وتكون مدته بين 30 و60 ثانية.

لتوليد فيديو من آية مأخوذة مباشرة من ملف Tanzil المتحقق منه:

```bash
python src/render_short.py --verse-key 2:255 --audio assets/audio/recitation.mp3
```

يمكن تمرير فيديو خلفية مرخّص:
`--background assets/backgrounds/scene.mp4`

عند عدم تمرير خلفية فيديو، ينشئ البرنامج خلفية طبيعية مرسومة بسيطة بحركة تقريب بطيئة. يحفظ الفيديو محلياً في `output/`.

يمكن إدخال النص يدوياً عبر `--verse` و`--surah` و`--ayah`، لكن هذا المسار لا يتحقق من النص القرآني؛ المسار الموصى به هو `--verse-key` بعد تنزيل بيانات Tanzil.

## ضوابط مهمة
- فحص البرنامج يتحقق من اكتمال 114 سورة و6236 آية وتتابع أرقامها ومطابقة العدد الوارد في بيانات السور؛ هذا فحص بنيوي وليس بديلاً عن مراجعة بشرية عند اعتماد المقطع النهائي.
- يجب مراجعة النص والتشكيل والمرجع قبل نشر أي فيديو.
- لا تستخدم أي تلاوة أو خط أو مشهد قبل التأكد من ترخيصه وشروط استخدامه على YouTube. إتاحة التلاوة للاستماع أو التنزيل لا تعني السماح بإعادة نشرها.
- لا تضع كلمات مرور أو مفاتيح API أو ملفات OAuth في المستودع.
- لا ينفّذ البرنامج رفعاً أو نشراً أو جدولة، ولا يتصل بواجهة YouTube.
- لا توجد GitHub Actions أو عمليات نشر تلقائي مفعّلة حالياً.
- لا يوجد نشر تجريبي.
