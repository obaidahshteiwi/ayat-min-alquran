# ملفات التلاوة

ضع التسجيل الذي تملك إذناً واضحاً بإعادة نشره في هذا المجلد.

قبل تشغيل المولّد:
1. انسخ `audio-rights.example.json` إلى `audio-rights.json`.
2. اكتب اسم القارئ والجهة المالكة واسم الترخيص.
3. سجّل رابط الترخيص مع نص الإسناد المطلوب، أو ضع مرجع إثبات الإذن المكتوب في ملف محلي.
4. غيّر `youtube_upload_allowed` إلى `true` فقط بعد التأكد الفعلي من أن الإذن يشمل رفع التسجيل إلى YouTube.
5. احتفظ بنسخة من الإذن. لا ترفع التسجيل أو مستندات الإذن إلى GitHub.

وجود ملف MP3 أو إمكانية تنزيله لا يعني أن إعادة نشره مسموحة. إذا لم يكن لديك إذن، لا تشغّل المولّد بهذا التسجيل.
