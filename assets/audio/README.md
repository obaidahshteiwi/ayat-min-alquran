# ملفات التلاوة

يوفر المشروع ملفاً مبدئياً لتلاوة سورة الفيل من Wikimedia Commons، وتعلن صفحة الملف عن رخصة CC0 1.0.

من جذر المشروع شغّل:

```bash
python scripts/fetch_starter_media.py
```

سيتحقق السكريبت من معلومات الترخيص في Commons، ونوع الملف، وحجمه، وبصمة SHA-1، ومدته، ثم يحفظه محلياً في `al-fil-105.mp3` وينشئ `audio-rights.json`.

ملاحظة: صفحة الملف تصف التلاوة بأنها برواية حفص ومرتّلة، لكن لا تذكر اسم القارئ بشكل منفصل في وصف الملف. لا تنسبها إلى قارئ محدد دون دليل من المصدر.

إذا أضفت تسجيلًا مختلفاً:
1. انسخ `audio-rights.example.json` إلى `audio-rights.json`.
2. اكتب صاحب الحقوق واسم الترخيص ورابطه والإسناد المطلوب، أو ضع ملف إثبات إذن محلياً.
3. لا تجعل `youtube_upload_allowed` تساوي `true` إلا بعد التحقق من أن الترخيص يسمح صراحة بإعادة نشر التسجيل على YouTube.
4. احتفظ بنسخة من الإذن. لا ترفع التسجيل أو مستندات الإذن إلى GitHub.

وجود ملف صوتي أو إمكانية تنزيله لا يعني أن إعادة نشره مسموحة.
