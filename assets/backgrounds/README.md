# الخلفيات

إذا لم تحدد فيديو خلفية، ينشئ المولّد خلفية مرسومة أصلية بسيطة من دون ملف خارجي.

عند استخدام فيديو خارجي:
1. ضع الملف المرخّص داخل هذا المجلد.
2. انسخ `background-rights.example.json` إلى `background-rights.json`.
3. وثّق صاحب الحقوق والترخيص ورابطه والإسناد المطلوب، أو مرجع الإذن المكتوب.
4. لا تغيّر `youtube_upload_allowed` إلى `true` إلا بعد التحقق من أن الترخيص يسمح بالنشر على YouTube.

لا ترفع ملفات الفيديو أو مستندات الإذن إلى GitHub.
