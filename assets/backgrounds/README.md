# الخلفيات

يوفر المشروع فيديو مبدئياً لنهر وضباب وغابة من Wikimedia Commons، وتعلن صفحة الملف عن رخصة CC0 1.0. مدته نحو 47 ثانية وحجمه نحو 60 MB.

من جذر المشروع شغّل:

```bash
python scripts/fetch_starter_media.py
```

سيتحقق السكريبت من بيانات الترخيص ونوع الملف والحجم وبصمة SHA-1 والمدة، ثم يحفظه محلياً وينشئ `background-rights.json`.

إذا أضفت فيديو مختلفاً:
1. ضع الملف في هذا المجلد.
2. انسخ `background-rights.example.json` إلى `background-rights.json`.
3. وثّق صاحب الحقوق والترخيص ورابطه والإسناد المطلوب أو ملف إثبات الإذن.
4. لا تجعل `youtube_upload_allowed` تساوي `true` إلا بعد التأكد من أن الترخيص يسمح برفعه إلى YouTube.

لا ترفع الفيديو أو مستندات الإذن إلى GitHub.
