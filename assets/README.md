# ملفات الوسائط والخطوط

ضع هنا فقط الملفات التي تملكها أو لديك إذن واضح بإعادة استخدامها على YouTube:

- `fonts/Amiri-Regular.ttf`: خط عربي مناسب، بعد التحقق من ترخيص الخط.
- `backgrounds/`: فيديوهات طبيعة مرخّصة، ويمكن تحديد أحدها في `config.json`.
- `audio/`: تلاوات مرخّصة، ويمكن تحديد ملف التلاوة في `config.json`.

لا يحتوي المستودع على تلاوات أو مشاهد خارجية افتراضية. لا ترفع ملفات محمية بحقوق النشر دون إذن.
