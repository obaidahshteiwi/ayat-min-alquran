# ملفات الوسائط والخطوط

ضع هنا فقط الملفات التي تملكها أو لديك إذن واضح بإعادة استخدامها على YouTube.

## الخط العربي
- يمكن استخدام خط Amiri المفتوح، مثل `Amiri-Regular.ttf`, بعد تنزيله من الموقع الرسمي: https://aliftype.com/amiri/
- رخصة Amiri هي SIL Open Font License؛ احتفظ بملف الرخصة وإسناد الخط عند إعادة توزيعه.
- تحقق بصرياً من ظهور علامات الرسم العثماني والضبط بصورة صحيحة قبل اعتماد الفيديو. لا تعتمد على اسم الخط وحده.

## الصوت والخلفيات
- `audio/`: تلاوات مرخّصة أو تسجيلات لديك إذن واضح باستخدامها.
- `backgrounds/`: مشاهد طبيعة مرخّصة، ويمكن تحديد أحدها في `config.json`.

لا يحتوي المستودع على تلاوات أو مشاهد خارجية افتراضية.

**تنبيه بشأن التلاوة:** إتاحة التسجيل للاستماع أو التنزيل لا تعني أن إعادة نشره في YouTube مسموحة. يجب الحصول على إذن واضح من القارئ أو الجهة التي تدير حقوق التسجيل، والاحتفاظ بمرجع الإذن. يوضح Quran.com أن حقوق التسجيلات تعود إلى القراء أو الجهات التي تديرها، وأنه لا يملك حق منح إذن إعادة استخدامها. لا ترفع ملفات محمية بحقوق النشر دون إذن.

## تثبيت خط Amiri محلياً

من جذر المشروع نفّذ:

```bash
python scripts/setup_assets.py
```

ينزّل السكريبت ملف `Amiri-Regular.ttf` وملف رخصة SIL OFL 1.1 من مستودع Amiri الرسمي عند commit محدد. لا يضيفهما إلى Git لأن `.gitignore` يستثنيهما. احتفظ بملف الرخصة عند استخدام الخط.
